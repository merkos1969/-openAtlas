## Έκδοση για GitHub με όλα τα αρχεία στη ρίζα

Αυτή η έκδοση δεν χρειάζεται φακέλους. Ανέβασε και τα 6 αρχεία απευθείας στη ρίζα του repository και αντικατάστησε τα παλιά: `index.html`, `app.js`, `style.css` (δεν απαιτείται, το CSS είναι ενσωματωμένο), `icon.svg`, `manifest.webmanifest`, `sw.js`, `README.md`.

Το CSS βρίσκεται μέσα στο `index.html`, ενώ το JavaScript και το εικονίδιο βρίσκονται δίπλα του στη ρίζα. Η εφαρμογή διατηρεί την τοπική ανάλυση PDF και την εκτύπωση/αποθήκευση PDF.
